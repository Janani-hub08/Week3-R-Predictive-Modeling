# Statistical Analysis & Predictive Modeling using R
**Internship Progress Report — Week 3**

## Executive Summary
This repository contains an end-to-end statistical analysis and machine learning project conducted in R. Using the Boston housing dataset, formal hypothesis testing was performed to analyze housing price drivers, followed by the training and diagnostic evaluation of a Multiple Linear Regression model with 10-Fold Cross-Validation.

## Summary of Results
- **Dataset:** Boston Housing (`MASS` package, 506 observations, 14 variables)
- **Hypothesis Test:** Pearson correlation confirmed a statistically significant relationship between room count (`rm`) and median price (`medv`) ($p < 2.2 \times 10^{-16}$).
- **Model Metrics:**
  - **$R^2$ Score:** `0.7046198` (Explains ~70.46% of price variance)
  - **Test RMSE:** `5.127298` (~$5,127 average error)
